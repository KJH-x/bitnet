# BitNet Windows x64 界面预览

这是带模拟数据的免安装预览。保持现有 BitNet 和 Bitgateway 正常运行即可，不需要管理员权限。

1. 解压 ZIP。用普通 PowerShell 进入解压后的目录，执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\preview-windows.ps1`。请从脚本启动，勿直接打开 EXE。
2. 打开后先确认窗口顶部有「模拟模式」。用虚构账户测试，也不要输入真实校园账号或密码。
3. 用虚构账号测试「验证并保存」。模拟密码填 `wrong` 应失败，换成 `demo-pass` 应成功。检查取消确认时表单和账户列表是否正确，再检查新增或改密失败后原账户是否仍在。
4. 查看侧栏底部、网卡和信任按钮、日志的时间列。对比常用显示缩放。滚动测试沿用 60 fps 截屏采样，记录每格的首帧延迟、中间位移帧数及停稳时间。对比原先 351–390 ms 的首帧数据，验收要求首帧 ≤100 ms 且有连续位移。
5. 完成后使用预览的 BitNet 托盘菜单退出。关闭主窗口只会隐藏界面。模拟数据保存在解压目录的 `.preview-data` 下。

反馈时请注明显示缩放比例、页面、操作顺序及预期与实际差异。真实网卡排序、校园网认证与系统服务操作不在这个预览的验收范围内。
