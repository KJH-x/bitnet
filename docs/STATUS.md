## 已得到的证据

- Windows x64 四个程序已构建：GUI、CLI、认证引擎、按需维护工具。使用独立 Iced 软件渲染，用户电脑不需要 Rust、Python、Node 或 WebView。
- Windows x64 实际生成 Client MSI、Service MSI 和 NSIS 一体安装器；Service MSI 在 Client MSI 内离线缓存。Minisign 项目签名已自行验证，使用明确标注的开发密钥，没有付费代码签名信誉。
- 网关协议有 25 项单元与 loopback 测试，覆盖算法、状态解析、绑定、响应上限、重定向和超时等边界；未向真实校园网登录或注销。
- Windows 凭据保护与原生平台测试、WSL Linux 平台测试通过；macOS 平台模块曾用项目私有 sysroot 完成 x86_64 交叉检查。交叉检查不代表真实 macOS Keychain、launchd、安装或运行通过。
- CLI/IPC 模拟联调验证账户元数据不返回密码、设置修订冲突、注销暂停跨重启、密码错误停止重试、换密恢复、导入不能绕过暂停或拒绝标记、停引擎后不会误启真实认证引擎。
- 新增运行时测试覆盖未知网络不自动发送凭据、导入不能新增网络信任、认证域锁竞争、多环境切换权限与暂停保留、IPv6 loopback 探测、自适应间隔，以及签名更新与下载攻击边界。
