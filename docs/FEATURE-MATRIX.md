## 本次补齐与剩余验收边界

1. 已补按“认证目标 origin + 来源 IPv4”域锁：Windows 命名 mutex、Linux 抽象 socket、macOS 文件锁；R 有域区分/竞争测试。跨身份、进程崩溃与实际多卡/网络命名空间仍须系统验收。
2. 已补未知网络信任门槛、一次性手动确认、导入防增信任及 profiles；R/E1/E2 覆盖相应边界。HTTP 门户与指纹仍不能提供服务器密码学身份保证，真实跨环境须验。
3. 已补稳定性自适应间隔、观测在线段/中断/重连耗时、IPv6 TCP 探测及恢复时间间隙检查。IPv6 地址/路由清单、真实网络/睡眠场景、长期观测仍需补验。
4. GUI 已接用户会话原生通知和更新策略：通知仅静态内容并去重；启动约 30 秒后检查、成功 24 小时、失败 1 小时。无 GUI 时不发桌面通知/不调度 GUI 更新；真实通知投递、生产 feed/key、签名产物、安装与回滚需发布验证。
5. 已补日志等级、重试/状态详情、逐事件保留天数过滤、系统模式 Event Log sink 和脱敏 Markdown Issue 模板。Event Log 的真实投递/消息资源显示、迁移向导仍待补验。
6. 三平台无人值守、跨用户 IPC、服务身份凭据重装稳定性、升级/卸载/回滚、最低 OS 版本及数周稳定性必须在隔离实机/VM 验收。macOS `/var/run` 已补 broker 初始化代码；冷启动、目录损坏及凭据拒绝路径仍须实机。
